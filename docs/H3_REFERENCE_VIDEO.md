# วิดีโอผ่าน fal: MiniMax H3 Max Reference to Video

ระบบเลือกใช้ `minimax/h3-max/reference-to-video` เพียงโมเดลเดียวสำหรับงานวิดีโอ คีย์ fal เดิมยังใช้ได้ การเริ่มระบบปรับโมเดลในค่าบริการ fal และปิดการใช้งานบริการวิดีโออื่น โดยเก็บข้อมูลเก่าและประวัติวิดีโอไว้

ตรวจ schema ทางการเมื่อ 29 กันยายน 2026:
- ภาพอ้างอิงสูงสุด 9 ภาพ
- วิดีโออ้างอิงสูงสุด 3 คลิป แต่ละคลิป 2–15 วินาที รวมไม่เกิน 15 วินาที
- เสียงอ้างอิงสูงสุด 3 คลิป แต่ละคลิป 2–15 วินาที รวมไม่เกิน 15 วินาที
- รวมภาพ วิดีโอ และเสียงไม่เกิน 12 ไฟล์
- ผลลัพธ์ยาว 5–15 วินาที เป็นจำนวนเต็ม; ความละเอียด 480P, 768P หรือ 1080P
- Prompt ไม่เกิน 50,000 ตัวอักษร; อ้างอิงตามลำดับ `Image 1`, `Video 1`, `Audio 1`

หน้าสร้างวิดีโอส่งภาพที่ผูกกับช็อตตามลำดับ ฉาก → ตัวละคร → สิ่งของ ผ่าน `reference_image_urls` ไม่ใช่ `image_url` หรือ Elements แยกตัวละคร ระบบแปลง @ชื่อเป็น Image N พร้อมตารางชื่อ ภาพซ้ำส่งเพียงครั้งเดียว จำนวนเกิน 9 แสดงคำเตือนก่อนส่ง ไม่ตัดทิ้งโดยเงียบ

ตัวเชื่อมรองรับ `reference_video_urls` และ `reference_audio_urls` ด้วย แต่หน้าผูกตัวละคร/ฉาก/สิ่งของปัจจุบันเลือกภาพเท่านั้น ข้อจำกัดระยะเวลาของไฟล์วิดีโอและเสียงอ้างอิงยังให้บริการ fal ตรวจ ไม่ได้ตรวจไฟล์ภายนอกล่วงหน้าในเครื่อง

คงบทพูดไทยใน prompt และปิด prompt expansion เพื่อรักษาคำสั่ง ยังต้องทดลองเสียงไทยจากผลลัพธ์จริงหลังใส่คีย์ ไม่ถือว่าการทดสอบ payload ยืนยันคุณภาพเสียงไทยแล้ว
