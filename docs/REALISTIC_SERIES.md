# สไตล์ภาพสมจริงสำหรับซีรีส์

เมนูสไตล์ภาพมี 6 แบบใหม่อยู่บนสุด:

| สไตล์ | เหมาะกับ |
| --- | --- |
| ซีรีส์สมจริง · ภาพยนตร์ | งานทั่วไป ภาพเหมือนถ่ายทำจริง แสงมีที่มา สีผิวธรรมชาติ |
| ซีรีส์ไทย · ดราม่าอบอุ่น | เรื่องร่วมสมัย บ้านและสถานที่จริง แสงหน้าต่าง โทนอุ่น |
| ซีรีส์เกาหลี · โรแมนติก | บทสนทนาใกล้ชิด แสงนุ่ม สีละมุน ผิวยังมีรายละเอียด |
| ซีรีส์สืบสวน · ระทึกขวัญ | บรรยากาศกดดัน แสงต่ำแต่ยังเห็นรายละเอียด |
| ซีรีส์ย้อนยุค · ฟิล์มคลาสสิก | เสื้อผ้า สิ่งของ และสถานที่สอดคล้องกับยุคที่ระบุ |
| สมจริง · สารคดีชีวิต | ท่าทางธรรมชาติ แสงที่มีอยู่จริง มุมระดับสายตา |

เลือกตอนสร้างโปรเจกต์ หรือแก้ไขสไตล์ของโปรเจกต์เดิม สไตล์มีผลกับภาพที่สร้างใหม่ ไม่แปลงภาพเดิมอัตโนมัติ ข้อมูลและสไตล์ที่ผู้ใช้แก้ไว้จะไม่ถูกเขียนทับตอนเริ่มระบบใหม่

## ขั้นตอนสำหรับ Codex

1. Export บริบทด้วย native CLI ตาม `CODEX_NATIVE.md` แล้วอ่าน `style_preset.prompt` หากไม่มี preset ให้ยึดบรีฟผู้ใช้แทน
2. ใช้ `imagegen` ของ OpenAI สำหรับสร้างภาพแบบ native และ `cinematography` จาก fal-ai-community สำหรับการกำกับภาพ ห้ามสลับไป genmedia CLI หรือ API สร้างภาพจากตัวอย่างใน skill
3. ล็อกลักษณะตัวละคร อายุ ทรงผม เสื้อผ้า และของที่ถือให้ต่อเนื่อง ใช้ภาพอ้างอิงตัวละครเดิมเมื่อมี
4. เขียนคำสั่งแต่ละช็อตตามลำดับ: คนและการกระทำ → สถานที่และเวลา → ระยะภาพและมุมกล้อง → เลนส์และความชัดลึก → แหล่งแสงและทิศทาง → โทนสี → ข้อกำหนดความต่อเนื่อง
5. ระบุแสงที่มีที่มา เช่น หน้าต่างทางซ้ายหรือโคมไฟบนโต๊ะ ไม่ใส่หลายทิศทางที่ขัดกัน รายละเอียดเลนส์เป็นแนวทางทางภาพ ไม่ใช่การรับประกันข้อมูล EXIF ของไฟล์
6. แยกภาพนิ่งจากคำสั่งเคลื่อนไหว: ภาพนิ่งบอกองค์ประกอบของเฟรม ส่วนวิดีโอเพิ่มการเคลื่อนกล้องและการกระทำเพียงช็อตเดียว ส่งให้ fal ผ่านระบบวิดีโอเดิม
7. ตรวจผิว มือ สายตา เครื่องแต่งกาย แสง และตำแหน่งสิ่งของ แล้ว attach ภาพจริงเข้าช็อตด้วย native CLI

ตัวอย่างบรีฟช็อต: “หญิงสาววัยผู้ใหญ่เปิดจดหมายในห้องนอนตอนค่ำ ภาพครึ่งตัว มุมกล้องระดับสายตา มุมมองเลนส์ 50 มม. แสงโคมไฟอุ่นจากซ้ายของเฟรม ผิวและเนื้อผ้าเป็นธรรมชาติ ฉากหลังยังอ่านเป็นห้องเดิม ใบหน้า ทรงผม เสื้อผ้า และจดหมายตรงกับภาพอ้างอิง ไม่มีตัวหนังสือหรือโลโก้”
