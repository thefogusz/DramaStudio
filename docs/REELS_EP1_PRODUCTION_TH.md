# ทดลองผลิตซีรีส์แนวตั้ง EP1

เรื่อง **อย่าเปิด** ตอน **คนส่งของสองคน** เป็นเรื่องต้นฉบับระทึกขวัญสมจริง ความยาว 40 วินาที (8 ช็อต ช็อตละ 5 วินาที) อัตราส่วน 9:16

## เปิดดูงาน

เมื่อ backend และ frontend ทำงาน เปิด http://localhost:3013/drama/2/preflight หรือเข้าเรื่อง “อย่าเปิด” แล้วเลือก “ตรวจภาพและบท”

หน้านี้แสดงภาพทุกช็อตเต็มเฟรม บท การกระทำ ช่วงเวลา prompt วิดีโอ และภาพอ้างอิงตัวละคร/ฉาก/พร็อป พร้อมตรวจว่ารูปโหลดจริงและอยู่ในสัดส่วนแนวตั้ง เส้นพื้นที่ปลอดภัยเป็นแนวทางจัดองค์ประกอบ ไม่รับประกันตำแหน่ง UI ของ Reels ทุกอุปกรณ์

## งานที่เตรียมแล้ว

- บทไทยพร้อมจุดเปิดเรื่อง การตัดสินใจและบทสรุป EP1 ก่อนทิ้งปม EP2
- ตัวละคร 2 คน ฉาก 3 แห่ง พร็อป 2 ชิ้น และภาพจริง 8 ช็อตจากเครื่องมือภาพ native
- การตรวจความต่อเนื่องโดย agent: ใบหน้า เสื้อผ้า โทรศัพท์/มือ ตำแหน่งประตู สลักหมุนด้านใน แสง และมุมมองตาแมว
- video prompt สำหรับแต่ละช็อต แผนเสียง แผนตัดต่อ และซับร่าง
- นำเข้าจริง drama ID 2 / episode ID 2 และทดสอบนำเข้าซ้ำโดยไม่สร้างตอนซ้ำ

ข้อมูลผลิตอยู่ใน `data/native/reels-dont-open-ep1/` (เป็นข้อมูลผู้ใช้ ไม่เก็บใน Git):

- `package.json` ชุดนำเข้าและรายการภาพที่เลือก
- `context-verified.json` ผลส่งออกจริงหลังแก้ระยะเวลารวม
- `agent-review.md` ผลตรวจจาก agent
- `ready-audit.json` หลักฐาน API 14 รายการและภาพ 30 รายการผ่าน backend 5679 และ frontend proxy 3013
- `script.txt`, `audio-plan.json`, `EDIT_PLAN_TH.md`, `subtitles-draft.srt`

## ขั้นตอนที่เหลือสำหรับเจ้าของงาน

ตรวจภาพและบท จากนั้นใส่ fal API key ในการตั้งค่า เลือกโมเดลก่อนเริ่มเจนวิดีโอ ชุดนี้เตรียมช็อตละ 5 วินาทีสำหรับ H3 / Kling 2.6 / Wan 2.6; หากเลือก Veo ต้องปรับระยะเวลาและแผนตัดต่อใหม่ตามตัวเลือกโมเดล

ยังไม่มีวิดีโอ เสียงจริง ซับที่ซิงก์จริง หรือคลิปรวม การพูดภาษาไทยและเสียงตัวละครให้เหมือนกันทุกคลิปต้องตรวจผลหลังเจน ช็อตสุดท้ายเป็นเสียงจากนอกประตูเลียนเสียงนลิน โดยนลินในภาพปิดปาก

ไม่ได้กดทดสอบหน้าจอจริง เนื่องจากเครื่องมือเบราว์เซอร์ปฏิเสธการเข้าถึง localhost; ตรวจจาก build, โค้ด, API และการดาวน์โหลดถอดรหัสภาพจริงแล้ว

## ระบบที่แก้ระหว่างทดลอง

- สถานะ pipeline นับตัวละครและฉากของตอนที่เลือก รวมภาพ first frame และไม่นับช็อตที่ลบ
- native import อัปเดตจำนวนตอน/เวลารวม และซ่อมยอดสรุปจากการนำเข้ารุ่นก่อนเมื่อ retry
- เพิ่มหน้าไทยสำหรับตรวจภาพและบทก่อนเจน พร้อมใช้ Noto Sans Thai ของแอป

ตรวจผ่าน backend typecheck, native tests, pipeline integration/status, storage/environment, fal tests และ frontend locale tests/build โดยไม่มีการเรียก API วิดีโอแบบเสียเงิน
